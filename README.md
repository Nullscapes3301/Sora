# Sora

En esta repo voy a aprovechar que aunque descontinuaron el servicio de Sora, nunca desinstale la app de mi telefono. Asi que voy a aprovechar para sacar la apk y subirla a GitHub.
Despues de una larga travesia y problemas con adb: SE PUDO!

## Metodo

Para sacar las apks de mi telefono active *opciones de desarrollador* y despues *depuracion inalambrica*. Despues conecte mi telefono a mi computador a travez de adb y extraje las apk para subirlas a github.
